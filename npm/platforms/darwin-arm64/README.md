# @coralogix/tsgo-strict-darwin-arm64

This package ships the prebuilt `tsgo-strict` CLI binary and N-API addon for **macOS arm64**. It is an optional dependency of
[`@coralogix/tsgo-strict`](https://www.npmjs.com/package/@coralogix/tsgo-strict);
install that instead and npm will pull in the right platform package for you.

```sh
npm install --save-dev @coralogix/tsgo-strict
```

See [coralogix/tsgo-strict](https://github.com/coralogix/tsgo-strict) for docs
and source.
