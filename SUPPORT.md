# Support

## Getting help

- Usage questions and troubleshooting: open a [GitHub Issue](https://github.com/coralogix/tsgo-strict/issues).
- Bug reports: use the bug report template.
- Security issues: see [`SECURITY.md`](./SECURITY.md). Report privately, not via a public issue.
- Documentation: <https://coralogix.github.io/tsgo-strict/>

## What to include

- `tsgo-strict` version
- Node.js version
- Operating system
- Exact command run
- Minimal reproducible configuration/project
